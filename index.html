A.I.R.A. System

Admin Inventory Request Application

A.I.R.A., or the CHK Admin Inventory Request Application, is strictly for use by CHK faculty and staff only. Any unauthorized requests will not be entertained.

The purpose of AIRA is to streamline and automate all supply requests and to collect accurate data on the most frequently requested supplies. This data will be used to support planning and preparation for the college's APP-CSE procurement requests.

⚠️ REMINDER: Please request only what is necessary and avoid stockpiling supplies. Usage patterns will be monitored to help ensure responsible and efficient use of resources.
